# Week05 Pendulum Simulation

## 人机协同三反思

1. **核心决策（由我决定）**：项目的整体目标、单摆模拟器的 UI 风格、交互方式（添加滑块）、以及基于浏览器报错信息判断修复方向。
2. **重复劳动（由 AI 完成）**：编写具体的 HTML/CSS/JS 代码结构、推导并实现复杂物理公式、执行 git commit 终端命令、快速定位代码中的语法错误。
3. **主体地位确认（HOTL）**：我是产品总设计师，负责定义"要做什么"和"好不好用"；AI 是高效的执行者，负责解决"怎么用代码实现"。
